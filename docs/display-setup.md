# Цифровая вывеска за витражом — бюджетное решение

## Почему монитор с Ozon не подходит

Портативные мониторы (типа [ozon.ru/t/zLCLJHr](https://ozon.ru/t/zLCLJHr)) — это **второй экран**. Им нужен постоянный источник: ноутбук, телефон, мини-ПК. Без него экран чёрный.

Для витрины нужно устройство, которое **само крутит контент с флешки** и включается после отключения света.

---

## Рекомендуемая схема (самая простая)

```
[Розетка] → [HDMI-рекламный плеер] → HDMI → [Монитор/ТВ]
                ↑
           [USB-флешка с MP4 или JPG]
```

### Что купить

| Компонент | Зачем | Бюджет (ориентир) |
|-----------|-------|-------------------|
| **HDMI-рекламный плеер** | Автозапуск, loop, без Wi‑Fi | 2 000–6 000 ₽ |
| **Монитор или ТВ** | Любой с HDMI; б/у — норм | 3 000–15 000 ₽ |
| **HDMI-кабель** | Плеер → экран | 200–500 ₽ |
| **USB-флешка 8–32 ГБ** | Один MP4 или папка JPG | уже есть |
| **Кронштейн / двусторонний скотч 3M** | Крепление за стеклом | 500–2 000 ₽ |

### На что смотреть в плеере

- **Автозапуск при подаче питания** — после ночного отключения света сам включится.
- **Loop / автоповтор** — крутит ролик или слайды по кругу.
- **USB + опционально SD** — обновление меню = заменил файлы на флешке.
- **Full HD (1080p)** — для витрины достаточно.
- **Без вентилятора** — меньше пыли в кофейне.
- **Портретная ориентация** (если есть в настройках) — для узкого вертикального окна.

### Примеры типов устройств (искать на Ozon / Яндекс Маркет)

- «Рекламный плеер HDMI USB автозапуск»
- «Digital signage player loop»
- Dekart DIPLAYER, Espada DMP, MCplayer Tiny Hdbox — профессиональные, надёжные.
- Бюджетные китайские «HDMI media player auto loop» — от ~1 500 ₽, проверять отзывы про автозапуск.

**Не путать** с обычным TV-box «для дома» (Xiaomi и т.п.) — там часто нужен пульт и ручной запуск.

## Есть ли HDMI-плееры с Wi‑Fi?

**Да.** Это отдельный класс — **сетевые / Digital Signage** плееры: HDMI на монитор, контент по Wi‑Fi или Ethernet (иногда ещё USB как запасной канал).

### Что обычно умеют

- Удалённая загрузка роликов/слайдов без поездки к флешке
- CMS / веб-кабинет: плейлисты, расписание, зоны на экране
- Автозапуск и loop после включения питания (как у USB-моделей)
- Часто Android + память внутри; контент кэшируется локально (показ не падает при кратком обрыве сети)

### Ориентир цен (РФ)

| Тип | Ориентир |
|-----|----------|
| USB-only, автозапуск + loop | ~2 000–8 000 ₽ |
| Сетевой Wi‑Fi / Ethernet (кафе, 1 экран) | ~6 000–20 000 ₽ |
| Проф. CMS / бренд-линейки | ~15 000–40 000+ ₽ |

Цены плавают — сверять на маркетах по отзывам про автозапуск 24/7.

### Ключевые слова для поиска

Ozon / Яндекс Маркет / спецмагазины:

- `сетевой рекламный плеер HDMI WiFi`
- `digital signage медиаплеер WiFi`
- `рекламный плеер Android CMS`
- категория: [Медиаплееры для рекламы](https://market.yandex.ru/category/mediapleyery-dlya-reklamy)

Типы устройств: сетевой DS-плеер (iconBIT DS и аналоги), Android-плеер с Signage/CMS, реже TV-box + kiosk-приложение (хуже для «включил и забыл»).

### Когда Wi‑Fi стоит брать, а когда USB

| Сценарий | Лучше |
|----------|--------|
| 1 экран CoffeeFriends, меню редко (раз в неделю / сезон) | **USB + HDMI-плеер** — текущий план с NC185B |
| Меняете меню часто или с телефона/из дома | **Wi‑Fi / сетевой** |
| Несколько точек / экранов с одного кабинета | **Wi‑Fi + CMS** |
| Нет стабильного Wi‑Fi за витриной | **USB** |

Для одной витрины Китежа USB-схема остаётся оптимумом по простоте и цене. Wi‑Fi — апгрейд, если обновления «по воздуху» начнут экономить время.

## Альтернативы (если плеер не найдёте)

| Вариант | Плюсы | Минусы | Цена |
|---------|-------|--------|------|
| **Старый Android-планшет** + приложение Fully Kiosk / Loop Slideshow | Гибко, Wi‑Fi | Нужен зарядка, батарея со временем | 0–5 000 ₽ |
| **Raspberry Pi Zero 2 + экран** | Полный контроль | Настройка сложнее | ~5 000 ₽+ |
| **Цифровая фоторамка 10–15"** | Совсем просто | Мелко за стеклом, слабая яркость | 2 000–8 000 ₽ |
| **Мини-ПК + автозапуск видео** | Мощно | Дороже, лишнее для меню | 8 000 ₽+ |

Для вашей задачи **рекламный HDMI-плеер — оптимум по цене и простоте**.

## Монитор: что взять

1. **Б/у офисный монитор 22–27"** — дёшево, яркость обычно хватает за стеклом днём, если не прямое солнце.
2. **Рекламный монитор** — дороже, выше яркость (300–500 nit), если витрина на солнце.
3. **Портативный монитор с Ozon** — только если к нему уже есть **плеер**, а не ноутбук.

### NSEOVS NC185B 18.5" (Ozon) + HDMI-плеер — **да, совместимо**

[Карточка на Ozon](https://www.ozon.ru/product/nseovs-18-5-monitor-usb-a-nc185b-ips-1920x1080-full-hd-120-gts-chernyy-3227205364/) — модель **NC185B** (линейка NC185A/B, один OEM-шаблон).

| Параметр | Значение | Для витрины |
|----------|----------|-------------|
| Видеовход | **Mini HDMI** + 2× USB-C (DP Alt Mode) | Плеер → HDMI-кабель → Mini HDMI на мониторе |
| USB-A в комплекте | **Только питание** (USB-A → USB-C), не DisplayLink | Плеер **не** питает экран по HDMI — нужен блок 5V/3A (в коробке) или USB-A от зарядки |
| Яркость | ~300 nit | За стеклом днём может быть тускло; вечер/тень — норм |
| Размер | 18.5", 1920×1080, IPS | Под узкую раму; VESA 75×75 |
| Ориентация | 16:9 landscape | Меню 9:16 → rotation в плеере или пересборка MP4 |

**Схема подключения:**

```
[Розетка] → [5V/3A адаптер] → USB-C (питание монитора)
[Розетка] → [HDMI-плеер] → HDMI → Mini HDMI (картинка)
[USB-флешка] → плеер
```

**Не путать:** «USB-A» в названии Ozon — про кабель питания, не про видео через USB. Монитор **не** DisplayLink и **не** требует драйверов Windows — стандартный HDMI-экран.

**Перед покупкой на Ozon:** в характеристиках должны быть **Mini HDMI** и **USB-C**; если указан только USB-A без HDMI — это другая модель, с плеером не заработает.

**Если яркости не хватит:** б/у офисный 22–24" (250–350 nit, но крупнее) или рекламный signage 400+ nit.

Узкая рама за стеклом → чаще выгоднее **вертикально**: в настройках плеера включить rotation 90° или снять вертикальное видео 9:16.

## Монтаж за витражом

1. Экран **внутри**, лицом к улице; провода и плеер — с внутренней стороны рамы.
2. Яркость: если бликует — слегка наклонить или матовая плёнка на стекло (не на экран).
3. Питание: удлинитель с **розеткой с выключателем** или умная розетка по расписанию.
4. Флешку обновлять: выключить → вынуть → заменить MP4 → вставить → включить.

---

## Формат контента на флешке

**Вариант А (проще):** один файл `menu.mp4`, 30–90 сек, loop.  
Собирается из слайдов меню — см. `docs/menu-workflow.md`.

**Вариант Б:** папка JPG + режим «слайдшоу» в плеере (если поддерживается), интервал 5–8 сек.

Рекомендуемое разрешение: **1080×1920** (вертикаль) или **1920×1080** (горизонталь) — под вашу раму.
