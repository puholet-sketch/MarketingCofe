## B. 5 вайбовых новинок (простые техкарты)

Правила: сиропы / концентраты / лёд / кофе / молоко / сливки / газировка. Без экзотики, 4–6 шагов.

### 1. Персик Тоник Эспрессо · Холодный кофе · 350 мл · **390 ₽**
Вайб: летний бамбл без апельсина, игристый.  
| Ингредиент | Граммовка |
|---|---|
| Эспрессо (двойной) | 36 г |
| Концентрат / сироп персик | 30 г |
| Газированная вода / тоник | 150 г |
| Лёд | 150 г |
| Цедра лимона (опц.) | 1 шт |

Сборка: лёд → персик → газировка → аккуратно эспрессо сверху.

### 2. Кокос Карамель Айс Латте · Сезонные · 350 мл · **370 ₽**
Вайб: пляжный десертный кофе.  
| Ингредиент | Граммовка |
|---|---|
| Эспрессо (двойной) | 36 г |
| Холодное молоко / кокосовое | 180 г |
| Сироп кокос | 15 г |
| Сироп карамель | 15 г |
| Лёд | 150 г |
| Карамельный топинг (опц.) | 5 г |

Сборка: сиропы на дно → лёд → молоко → эспрессо → топинг.

### 3. Малина Сливки Фраппе · Холодный кофе · 400 мл · **400 ₽**
Вайб: ягодный шейк-кофе, быстро блендером.  
| Ингредиент | Граммовка |
|---|---|
| Эспрессо (двойной) | 36 г |
| Молоко | 120 г |
| Сливки 10–20% | 40 г |
| Сироп / пюре малина | 30 г |
| Лёд | 180 г |
| Сахарный сироп (по вкусу) | 10 г |

Сборка: всё в блендер 10–15 сек.

### 4. Лаванда Хани Раф Айс · Авторские · 350 мл · **420 ₽**
Вайб: мягкий «дорогой» аромат, простой микс.  
| Ингредиент | Граммовка |
|---|---|
| Эспрессо (двойной) | 36 г |
| Сливки + молоко 1:1 | 200 г |
| Сироп лаванда | 15 г |
| Сироп / мёд жидкий | 10 г |
| Лёд | 120 г |

Сборка: сиропы + молоко/сливки взбить → лёд → эспрессо.

### 5. Юдзу Сода Кофе · Холодный кофе · 350 мл · **380 ₽**
Вайб: цитрус + газ, «японский» летний шот. Если нет юдзу — сироп лимон-лайм / юзу-заменитель.  
| Ингредиент | Граммовка |
|---|---|
| Эспрессо (двойной) | 36 г |
| Сироп юдзу / лимон-лайм | 25 г |
| Газированная вода | 160 г |
| Лёд | 150 г |
| Щепотка соли | 1 г |

Сборка: лёд → сироп → соль → газировка → эспрессо сверху.
